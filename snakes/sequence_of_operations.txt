Sequence of Operations in the Snake Game:

1.  **main.py**: This is the entry point of the game. It initializes the game screen, creates instances of `Scoreboard`, 
    `Snake`, and `Food` objects. It then sets up event listeners for keyboard inputs to control the snake\'s movement and to quit the game.
    The game loop also handles collision detection with walls and the snake\'s own tail, triggering a `game_over` state and resetting the game.

2.  **Snake Game Loop (main.py)**: The `while game_is_on` loop continuously updates the game state:
    *   `screen.update()` and `time.sleep(.1)`: Refreshes the screen and pauses briefly to control the animation speed.
    *   `snake.move()`: Calls the `move` method in the `snake.py` module to update the position of the snake\'s segments.
    *   `snake.border_crossing()`: Checks if the snake has hit the screen borders and, if so, adjusts its position and changes its direction randomly.
    *   **Food Interaction**: If the snake\'s head is close to the `food` object (`snake.head.distance(food) < 20`):
        *   `food.refresh()`: The `food` object (from `food.py`) is moved to a new random location.
        *   `scoreboard.increase_score()`: The `scoreboard` object (from `scoreboard.py`) updates and displays the increased score.
    *   **Collision Detection (Walls and Tail)**: If the snake collides with the screen boundaries or its own tail:
        *   `game_is_on` is set to `False` to end the current game round.
        *   `scoreboard.reset()`: Resets the scoreboard, updating the high score if the current score is greater.
        *   `snake.reset_snake()`: Resets the snake\'s position and length for a new game round.

3.  **food.py**: Defines the `Food` class, which inherits from `Turtle`. It handles:
    *   Initialization: Sets the food\'s shape, color, and initial random position.
    *   `refresh()`: Moves the food to a new random `(x, y)` coordinate on the screen after it\'s eaten.

4.  **scoreboard.py**: Defines the `Scoreboard` class, also inheriting from `Turtle`. It manages:
    *   Initialization: Sets up the score display at the top of the screen with an initial score of 0, and loads the high score from `data.txt`.
    *   `update_scoreboard()`: Clears the current score display and rewrites the updated score and high score.
    *   `increase_score()`: Increments the current score and calls `update_scoreboard()`.
    *   `game_over()`: Displays a \'GAME OVER\' message when the game ends.
    *   `reset()`: Resets the current score to 0, updates the high score if applicable, saves the high score to `data.txt`, and refreshes the scoreboard display.
    *   `load_high_score()`: Reads the high score from a `data.txt` file.
    *   `save_high_score()`: Writes the current high score to the `data.txt` file.

5.  **snake.py**: Defines the `Snake` class, which is composed of multiple `Turtle` objects as segments. It handles:
    *   Initialization: Creates the initial snake body and sets the head segment.
    *   `create_snake()`: Builds the snake by creating and positioning `Turtle` segments.
    *   `reset_snake()`: Clears existing segments and rebuilds the snake to its initial state.
    *   `move()`: Moves the snake forward by iterating through its segments and updating their positions.
    *   `up()`, `down()`, `left()`, `right()`: Methods to change the snake head\'s direction based on keyboard input, preventing immediate reverse movement.
    *   `border_crossing()`: Detects if the snake hits the screen boundaries and, if so, repositions it and changes its direction randomly to keep it on screen.

**Overall Flow**:

The `main.py` script orchestrates the game by setting up the environment, initializing game objects, and running the main game 
    loop. Within this loop, the `snake` object\'s movement is continuously updated, and interactions with `food` and `scoreboard` are managed. 
    Collision detection is also handled in `main.py`, triggering game over and reset conditions. The `food.py`, `scoreboard.py`, and `snake.py` modules provide specialized functionalities for their respective game 
    elements, defining the core behavior and appearance of the snake, food, and score display.
